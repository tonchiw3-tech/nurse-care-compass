# Nurse Care Compass

看護師・看護学生の健康管理と、看護管理者による面談・フォロー支援を目的としたアプリです。

## ターゲット

- 看護学生
- 新人看護師
- 若手看護師
- 看護管理者

## 目的

- 看護師自身が日々の体調や勤務状況を記録する
- 睡眠、疲労、休憩、腰痛などの変化を振り返る
- 1か月・1年間の傾向を確認する
- 必要な場合は管理者へ相談希望を伝える
- 管理者が面談やフォローに活用する

## 主な機能

- 勤務区分の記録
- 超過勤務時間の記録
- 睡眠時間の記録
- 疲労感の記録
- 休憩状況の記録
- 腰痛の記録
- 今日のひとことメモ
- 音声入力
- 記録履歴
- 月ごとの平均・グラフ表示
- 管理者ログイン
- 面談記録
- 面談スケジュール
- フォロー予定管理

## プライバシー

本人の記録を基本とし、管理者への共有は本人が選択できる設計を想定しています。

他のスタッフが他者の健康情報を閲覧できないようにすることを目標としています。

## 現在の開発状況

現在は試作版です。

HTML / CSS / JavaScript を使って開発しており、記録データは一部 localStorage に保存しています。

今後は、Spring Boot + MySQL を使用したログイン・権限管理・データベース保存への発展を予定しています。
